# Code copied into this package

This package keeps a few small files and checks that other packages also have. Each one is listed here with its source and what changed, so that a fix in one copy goes into each copy, and the commit names all of them.

| Copy                                                                                     | Source                                                                                                                                                                     | What changed                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | Backlog                                                                                                                                       |
| ---------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `sshArgs` of `DockerHost` in `src/docker/host.ts`                                        | `sshArguments` in `packages/docker/src/ssh-connection.ts`                                                                                                                  | Both make the `ssh` arguments for an `ssh://` URL: `-T`, `BatchMode=yes`, the user with `-l` and the port with `-p`. The copy adds `ConnectTimeout=10`, `ServerAliveInterval=10` and `ServerAliveCountMax=2`, takes extra options before the host, and runs a shell command or a forward, not `docker system dial-stdio`. It does not remove the brackets of an IPv6 address, and it puts no `--` before the host.                                                                                                                                                                                                                                                                   | — (root ADR 0001 rule 4: a tiny helper stays a copy)                                                                                          |
| `src/testing/fake-engine.ts`                                                             | `packages/docker/src/testing/fake-engine.ts`                                                                                                                               | Nothing.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | — (test helpers stay copied)                                                                                                                  |
| `EngineLease` in `src/docker/engine-lease.ts`                                            | `Claims.create`, `Claims.waitForRelease`, `removeUnlessRunning` and the attach and start of `Claim.hold` in `packages/mutex/src/lock-stores/docker/docker-engine-store.ts` | Both hold a container that runs `cat` on the standard input of an attach, with AutoRemove. Both attach before the start. A name conflict and a removal before the start give no lease. A waiter removes a lease that stays `created` or that ended, without force, and waits for a `running` one. The copy attaches with `ref: false`, because a test process holds its lease for its whole life. It mints no fencing token, has no heartbeat and no queue in memory: a lease only tells a sweep that a holder lives. The image is pinned (`busybox:1.37.0`), and the caller pulls it. The time that a waiter gives a `created` lease is a constant of 5 s, not `heartbeatInterval`. | Main session files it: the third copy extracts the lease. Until then, a fix in one copy goes into the other, and the commit names both files. |
| The parse of the last line in `scenario` of `src/docker/ssh-forward.integration.test.ts` | `lastJson` in `packages/docker/src/testing/scenario.ts`                                                                                                                    | Both parse the last line of the standard output of a Node process as JSON. The copy is one inline expression. It does not trim the output, because `nano-spawn` removes the last newline. It does not throw an error that shows the standard error when the process wrote no line.                                                                                                                                                                                                                                                                                                                                                                                                   | — (test helpers stay copied)                                                                                                                  |

The tests of this package reach an SSH engine through a stand-in for `ssh` that pipes `docker system dial-stdio` to the fake engine. Thus they need the fake engine of the docker package, and the docker package does not export its test helpers. For the same reason, the SSH forward test keeps its own parse of the last line of a scenario.
