# Code copied into this package

This package keeps a few small files and checks that other packages also have. Each one is listed here with its source and what changed, so that a fix in one copy goes into each copy, and the commit names all of them.

| Copy                                              | Source                                                    | What changed                                                                                                                                                                                                                                                                                                                                                                                                       | Backlog                                              |
| ------------------------------------------------- | --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------- |
| `sshArgs` of `DockerHost` in `src/docker/host.ts` | `sshArguments` in `packages/docker/src/ssh-connection.ts` | Both make the `ssh` arguments for an `ssh://` URL: `-T`, `BatchMode=yes`, the user with `-l` and the port with `-p`. The copy adds `ConnectTimeout=10`, `ServerAliveInterval=10` and `ServerAliveCountMax=2`, takes extra options before the host, and runs a shell command or a forward, not `docker system dial-stdio`. It does not remove the brackets of an IPv6 address, and it puts no `--` before the host. | — (root ADR 0001 rule 4: a tiny helper stays a copy) |
| `src/testing/fake-engine.ts`                      | `packages/docker/src/testing/fake-engine.ts`              | Nothing.                                                                                                                                                                                                                                                                                                                                                                                                           | — (test helpers stay copied)                         |

The tests of this package reach an SSH engine through a stand-in for `ssh` that pipes `docker system dial-stdio` to the fake engine. Thus they need the fake engine of the docker package, and the docker package does not export its test helpers.
