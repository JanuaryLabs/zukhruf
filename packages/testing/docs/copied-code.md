The tests of this package reach an SSH engine through a stand-in for `ssh` that pipes `docker system dial-stdio` to the fake engine. Thus they need the fake engine of the docker package, and the docker package does not export its test helpers. For the same reason, the SSH forward test keeps its own parse of the last line of a scenario.
