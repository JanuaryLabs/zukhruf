# Code copied in this package

This package keeps code that another place also has. Each copy is listed here with its source and what changed, so that a fix in one copy goes into each copy, and the commit names all of them.

| Copy                               | Source                                                                      | What changed                                                                                                                                                                                                                                                                                                                                                                                 |
| ---------------------------------- | --------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/testing/scratch-directory.ts` | `TemporaryFiles` in `packages/fs/src/temporary-files.ts`, as docker kept it | One fixed prefix, `sqlite-open-test-`, and 5 retries of 20 ms; no `parent` option and no sync form. It gives the real path, because a test compares the path that SQLite reports. It stays a copy because of a cycle: `@zukhruf/fs` depends on this package, so its tests cannot import `@zukhruf/fs` ([root ADR 0001](../../../../docs/adr/0001-zukhruf-is-a-layered-standard-library.md)). |
