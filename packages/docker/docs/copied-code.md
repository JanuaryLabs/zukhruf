# Code copied in this package

This package keeps code that another place also has. Each copy is listed here with its source and what changed, so that a fix in one copy goes into each copy, and the commit names all of them.

| Copy                                                                                                                                                                       | Source                                                                                                                        | What changed                                                                                                                                                                                                                                                                                                                                  |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/testing/scratch-directory.ts`                                                                                                                                         | `packages/mutex/src/testing/scratch-directory.ts` (deleted: the other packages use `TemporaryFiles` of `@zukhruf/testing/fs`) | The folder name starts with `docker-test-`. The comment is shorter: no lock store holds a file open here, but the retries stay for Windows. It stays a copy because of a cycle: docker cannot import `@zukhruf/testing`, which depends on docker ([root ADR 0001](../../../docs/adr/0001-zukhruf-is-a-layered-standard-library.md), line 29). |
| The `X-Registry-Auth` header in `push()` of `src/images.ts`                                                                                                                | The `X-Registry-Auth` header in `pull()` of `src/images.ts`                                                                   | Nothing. Both encode the credentials as JSON in padded base64url for the header, because Moby decodes it with the padded `URLEncoding` of Go.                                                                                                                                                                                                 |
| `connect` in `src/attach.test.ts`, `src/containers.test.ts`, `src/exec.test.ts`, `src/files.test.ts`, `src/logs.test.ts`, `src/networks.test.ts` and `src/volumes.test.ts` | Each other                                                                                                                    | Nothing. The seven copies are byte-identical. Each one connects to the engine of the test environment with a timeout of 15 s, and pulls `alpine:3` when the engine does not have it. `connectWithHello` in `src/images.test.ts` is an eighth place with the same knowledge: it pulls `hello-world`.                                           |

Test helpers stay copied, also after a third copy ([ADR 0001 of zukhruf](../../../docs/adr/0001-zukhruf-is-a-layered-standard-library.md), rule 2). On 2026-10-26 the maintainer moved into `@zukhruf/testing` only the test helpers whose knowledge is in three or more repositories. The knowledge of `connect` is only in this repository. Also, the tests of this package cannot import `@zukhruf/testing`, because that import makes a cycle in the build. Thus `connect` stays in eight places. A fix to one place goes into each place, and the commit names each file.

The `X-Registry-Auth` header is in two places of one package. This project counts places, not packages, so two places stay copies until a third place needs the header, for example a build or a login. Then the header moves into one function, and both copies go. Until then, a fix of the header goes into both places, and the commit names both (zukhruf backlog: "the X-Registry-Auth header is written twice").
