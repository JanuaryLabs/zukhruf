# Code copied in this package

This package keeps code that another place also has. Each copy is listed here with its source and what changed, so that a fix in one copy goes into each copy, and the commit names all of them. A test helper of this package moves into `src/testing/` at its third place (root ADR 0001, rule 2), as `src/testing/dial.ts` and `src/testing/silent-server.ts` did.

| Copy                                                  | Source                                            | What changed                                                                                                                                                                                                                                   |
| ----------------------------------------------------- | ------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `startOwner` in `src/config-dial-route.test.ts`       | `startOwner` in `src/owner-death.test.ts`         | The child script (`src/testing/config-owner.ts` in place of `src/testing/owner.ts`) and its arguments. Both start a child Node process and wait for its `ready` line, or its exit. A third place moves it into `src/testing/`.                 |
| `listen` in `src/control.test.ts`                     | `listen` in `src/owner-death.test.ts`             | The control test's server does not read the data of its connections. Both destroy the open connections at disposal, so a failed test ends at its limit.                                                                                        |
| The connect-timeout test in `src/config-dial.test.ts` | The `connectTimeout` test in `src/client.test.ts` | The subject: `OpenSshConfig#dial` under `ConnectTimeout`, against `Client.dial` under `connectTimeout`. Both move the fake clock to 1 ms before the limit, check that the dial has not settled, then move it 1 ms and expect a `TimeoutError`. |
